# Welcome to Asante Trade! 🌍

Thank you for your interest in contributing to Asante Trade. We're building financial inclusion tools for Africa, and we'd love your help!

## What is Asante Trade?

Asante Trade empowers field agents to sell financial services — mobile wallets, remittances, savings, bill payments — to underbanked communities across Africa using the speed and low costs of Stellar blockchain.

This repository contains the web dashboards that help manage agent networks, compliance, and product configuration.

## What's in This Repository?

- **Home Page**: Beautiful, interactive landing page showcasing the platform
- **Admin Dashboard**: Foundation for head office staff to manage agent networks
- **Documentation**: Comprehensive guides for developers and contributors
- **Brand Assets**: Asante Trade logos and color scheme
- **Developer Setup**: Everything configured and ready to go

## I Want to Help! Where Do I Start?

### Step 1: Read the Essentials
- [README.md](README.md) - Project overview
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) - Community standards
- [CONTRIBUTING.md](CONTRIBUTING.md) - How to contribute

### Step 2: Set Up Locally
```bash
git clone https://github.com/Asante-Trade/asante-trade-web.git
cd asante-trade-web
pnpm install
pnpm dev
```

Visit http://localhost:3000 to see the home page.

### Step 3: Find Something to Work On
1. Browse [GitHub Issues](https://github.com/Asante-Trade/asante-trade-web/issues)
2. Look for `good first issue` or `help wanted` labels
3. Comment: "I'd like to work on this"
4. Wait for confirmation to avoid duplicate work

### Step 4: Make Your First Contribution
- Follow [docs/FIRST_CONTRIBUTION.md](docs/FIRST_CONTRIBUTION.md)
- Ask questions in [GitHub Discussions](https://github.com/Asante-Trade/asante-trade-web/discussions)
- Submit a PR with your changes
