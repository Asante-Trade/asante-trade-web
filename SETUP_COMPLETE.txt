💡 KEY DECISIONS
================================================================================

Framework: Next.js 16 (App Router)
  → Modern React, great DX, easy deployment to Vercel
  
Language: TypeScript (strict mode)
  → Type safety, better IDE support, fewer runtime errors
  
Styling: Tailwind CSS
  → Fast, utility-first, built-in brand colors, responsive
  
Package Manager: pnpm
  → Faster, disk space efficient, great monorepo support
  
Monorepo: pnpm workspaces
  → Scalable structure ready for multiple apps and shared packages
  
Theme: Dark (professional fintech)
  → Brand-appropriate for financial services platform
