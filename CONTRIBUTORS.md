# Contributors

Thank you to everyone who has contributed to Asante Trade! 🙏

## Getting Your Name Here

Contributions can take many forms:

- Code (features, bug fixes, refactoring)
- Documentation (guides, examples, clarifications)
- Design (UI/UX, graphics, brand assets)
- Triage (issue management, community support)
- Testing (bug reports, feedback)
- Translation (localization)

To be added to this list, simply make a contribution and reference this file in your PR description.
