# Roadmap

Asante Trade is in active development. This roadmap reflects our priorities and is informed by community feedback.

## Current Phase: Foundation

### Q1 2024
- [x] Repository scaffolding
- [x] Initial home page with brand guidelines
- [ ] Admin dashboard structure
- [ ] Basic navigation and layout

### Q2 2024 (In Progress)
- [ ] Agent network management UI
- [ ] KYC/AML compliance view
- [ ] User authentication
- [ ] Basic data persistence

## Near Term: Core Features

### Admin Dashboard
- Agent network management
  - View all agents
  - Agent registration and onboarding
  - Performance metrics
  - Territory management
- Compliance & KYC/AML
  - Document verification
  - Risk assessments
  - Audit logs
- Product configuration
  - Mobile wallets
  - Remittances
  - Savings products
  - Bill payments

### Shared Infrastructure
- UI component library (`packages/ui`)
- Utility functions (`packages/utils`)
- TypeScript types (`packages/types`)
- Stellar integration helpers (`packages/stellar`)

## Medium Term: Additional Dashboards

### Manager Dashboard
- Territory performance metrics
- Team oversight
- Agent performance tracking
- Regional reporting

### Customer/Trainer Portal
- Self-service functionality
- Training resources
- Customer support interface
- Account management

## Long Term: Blockchain Integration

### Stellar Integration
- Smart contract development
- Wallet management
- Transaction processing
- Payment settlement

### Advanced Features
- Real-time analytics
- Machine learning for fraud detection
- Mobile app integration
- Multi-language support

## Contributing to the Roadmap

We'd love your input! You can:

1. **Open an Issue** - Suggest a feature or improvement
2. **Start a Discussion** - Ask about priorities or offer insights
3. **Vote on Issues** - Add reaction emojis to issues you care about
4. **Comment** - Provide feedback on proposed features

## How We Prioritize

We consider:
- **Impact** - How many users/agents will benefit?
- **Feasibility** - Can we build it with current resources?
- **Dependencies** - Does it depend on other features?
- **Community Feedback** - What do contributors and users want?
